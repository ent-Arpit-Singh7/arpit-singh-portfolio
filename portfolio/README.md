# Arpit Singh Portfolio

This project is a complete, responsive, semantic HTML5 and CSS3 portfolio website for Arpit Singh.

## Structure

- index.html — Home page
- about.html — About page
- projects.html — Projects page with six project cards
- contact.html — Accessible contact page with a form
- css/style.css — External stylesheet
- images/ — Placeholder asset directory

## Features

- Semantic HTML5 landmarks and content structure
- WCAG 2.2-friendly accessibility practices
- Sticky navigation and keyboard-friendly interactions
- Responsive layout using Flexbox and CSS Grid
- SEO metadata and social sharing tags
